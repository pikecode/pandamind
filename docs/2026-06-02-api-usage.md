## 认证

### POST /v1/auth/login

获取 JWT Token。

```bash
curl -X POST http://localhost:8000/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"changeme"}'
```

**Response:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

> `AUTH_DISABLED=true` 仅用于本地开发。生产环境必须保持 `AUTH_DISABLED=false`，并设置强密码和 `JWT_SECRET`。

### 无鉴权模式（内部系统调用）

当 `AUTH_DISABLED=true` 时，所有接口无需 `Authorization` header，适合内部系统直接调用。

**配置**：
```bash
# .env
AUTH_DISABLED=true
```

**调用示例**：
```bash
# 列出模型（无需 token）
curl http://localhost:8000/v1/models

# 对话（无需 token）
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"ollama-llama3-default","messages":[{"role":"user","content":"hello"}]}'

# Process（无需 token）
curl -X POST http://localhost:8000/v1/process \
  -H "Content-Type: application/json" \
  -d '{"text":"hello","prompt_id":"general-assistant"}'
```

**注意事项**：
- 仅用于内部网络，不可暴露到公网
- 生产环境必须关闭（`AUTH_DISABLED=false`）
- 无法区分不同用户，所有请求视为匿名用户

## 模型管理

> 以下示例使用 `$TOKEN` 变量。当 `AUTH_DISABLED=true` 时，可省略 `-H "Authorization: Bearer $TOKEN"`。

### GET /v1/models

列出所有模型配置。

**有鉴权**：
```bash
curl http://localhost:8000/v1/models \
  -H "Authorization: Bearer $TOKEN"
```

**无鉴权**（`AUTH_DISABLED=true`）：
```bash
curl http://localhost:8000/v1/models
```

### POST /v1/models

创建模型配置。

```bash
curl -X POST http://localhost:8000/v1/models \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "name": "Local Llama 3",
    "provider": "ollama",
    "model": "llama3:8b",
    "base_url": "http://127.0.0.1:11434",
    "aliases": ["local", "fast"],
    "enabled": true
  }'
```

### GET /v1/models/{id}/ping

检测模型可用性。

```bash
curl http://localhost:8000/v1/models/ollama-llama3-default/ping \
  -H "Authorization: Bearer $TOKEN"
```

**Response:**
```json
{
  "model_id": "ollama-llama3-default",
  "health": {
    "status": "reachable",
    "latency_ms": 31.0
  }
}
```

## 对话接口

> 以下示例使用 `$TOKEN` 变量。当 `AUTH_DISABLED=true` 时，可省略 `-H "Authorization: Bearer $TOKEN"`。

### POST /v1/chat/completions

OpenAI 兼容式对话接口，支持流式和非流式。

#### 非流式

**有鉴权**：
```bash
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "model": "ollama-llama3-default",
    "messages": [
      {"role": "user", "content": "Say hello in 3 words"}
    ],
    "stream": false
  }'
```

**无鉴权**（`AUTH_DISABLED=true`）：
```bash
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ollama-llama3-default",
    "messages": [
      {"role": "user", "content": "Say hello in 3 words"}
    ],
    "stream": false
  }'
```

**Response:**
```json
{
  "id": "xxx",
  "object": "chat.completion",
  "model": "ollama-llama3-default",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Hello, how are"
      },
      "finish_reason": "stop"
    }
  ]
}
```

#### 流式 (SSE)

**有鉴权**：
```bash
curl -N -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "model": "ollama-llama3-default",
    "messages": [
      {"role": "user", "content": "Say hello"}
    ],
    "stream": true
  }'
```

**无鉴权**（`AUTH_DISABLED=true`）：
```bash
curl -N -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ollama-llama3-default",
    "messages": [
      {"role": "user", "content": "Say hello"}
    ],
    "stream": true
  }'
```

**Response (SSE):**
```
data: {"id":"...","choices":[{"delta":{"content":"Hello"}}]}

data: {"id":"...","choices":[{"delta":{"content":"!"}}]}

data: [DONE]
```

### DELETE /v1/chat/{stream_id}

取消流式请求。

```bash
curl -X DELETE http://localhost:8000/v1/chat/yJ5qZSUToojSGrcPRbcaK \
  -H "Authorization: Bearer $TOKEN"
```

## 处理接口

> 以下示例使用 `$TOKEN` 变量。当 `AUTH_DISABLED=true` 时，可省略 `-H "Authorization: Bearer $TOKEN"`。

### POST /v1/process

**场景**: 外部系统需要调用模型处理能力，传入文本和提示词模板 ID，返回处理后的结果。

**有鉴权**：
```bash
curl -X POST http://localhost:8000/v1/process \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "text": "Translate to French: Hello world",
    "prompt_id": "general-assistant",
    "model": "ollama-llama3-default",
    "variables": {
      "question": "Translate to French: Hello world"
    }
  }'
```

**无鉴权**（`AUTH_DISABLED=true`）：
```bash
curl -X POST http://localhost:8000/v1/process \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Translate to French: Hello world",
    "prompt_id": "general-assistant",
    "model": "ollama-llama3-default",
    "variables": {
      "question": "Translate to French: Hello world"
    }
  }'
```

**Parameters:**

| 字段 | 必填 | 说明 |
|-------|------|------|
| `text` | 是 | 输入文本 |
| `prompt_id` | 是 | 提示词模板 ID |
| `model` | 否 | 模型 ID（默认第一个可用模型） |
| `variables` | 否 | 额外的模板变量 |

**Response:**

```json
{
  "result": "Bonjour monde",
  "model": "ollama-llama3-default",
  "prompt_id": "general-assistant",
  "latency_ms": 7286
}
```

### Python 示例

```python
import requests

resp = requests.post(
    "http://pandamind:8000/v1/process",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "text": user_input,
        "prompt_id": "code-assistant",
        "model": "ollama-llama3-default",
        "variables": {
            "language": "Python",
            "specialty": "backend"
        }
    }
)
result = resp.json()["result"]
```

## 提示词管理

### GET /v1/prompts

列出所有提示词模板。

```bash
curl http://localhost:8000/v1/prompts \
  -H "Authorization: Bearer $TOKEN"
```

### POST /v1/prompts

创建提示词模板。

```bash
curl -X POST http://localhost:8000/v1/prompts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "name": "翻译助手",
    "system": "You are a translator.",
    "user_template": "Translate to {{target_lang}}: {{text}}",
    "variables": [
      {"name": "target_lang", "required": true},
      {"name": "text", "required": true}
    ],
    "tags": ["translate"]
  }'
```

### POST /v1/prompts/{id}/render

渲染提示词模板（预览）。

```bash
curl -X POST http://localhost:8000/v1/prompts/general-assistant/render \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "variables": {
      "question": "What is AI?"
    }
  }'
```

**Response:**
```json
{
  "system": "You are a helpful assistant...",
  "user": "What is AI?",
  "variables": {"question": "What is AI?"}
}
```

## 快速启动

```bash
# 1. 启动后端
PYTHONPATH=src uv run uvicorn pandamind.main:app --reload

# 2. 登录获取 Token
TOKEN=$(curl -s -X POST http://localhost:8000/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"changeme"}' | \
  python3 -c "import sys,json;print(json.load(sys.stdin)['access_token'])")

# 3. 测试对话
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"model":"ollama-llama3-default","messages":[{"role":"user","content":"Hello"}]}'
```
